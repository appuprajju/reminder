Privacy Policy for reminderme

Effective Date: November 27, 2026 · Website: https://reminder.makeuperfect.in · Developer: Prajwal M (</yourstudio>) · Contact: appuprajju807@gmail.com

This Privacy Policy explains how reminderme, accessible at https://reminder.makeuperfect.in, collects, uses, stores, protects, and deletes your information when you create alarms, daily reminders, voice reminders, and optional Google Workspace integrations.

1. Information We Collect

  • On-Device Reminder & Preference Data (Guest Mode): Stored locally on your device using browser/device storage when not signed in.
  • Account Information (Optional Sign-In): Name, email address, user ID, optional profile photo, and timezone via Firebase Authentication.
  • Synced Reminders & Schedules: Stored privately under your authenticated user ID in Firebase Cloud Firestore.
  • Voice Capture (Optional): Speech recognition runs via your device’s built-in speech engine; reminderme never records or uploads microphone audio.
  • Notifications & Alarms (Optional): Used solely to trigger scheduled alarms and reminders on time.

2. Google User Data & Google Workspace API Usage

If you connect Google Calendar or Gmail inside reminderme, the App uses these scopes strictly for user-requested features:

  • Google Calendar (https://www.googleapis.com/auth/calendar.events): Displays upcoming events beside reminders and creates events only after your explicit confirmation.
  • Gmail Read-Only (https://www.googleapis.com/auth/gmail.readonly): Displays recent primary inbox metadata so you can turn an email into a reminder in one tap; email content is never stored on external servers.
  • Gmail Send (https://www.googleapis.com/auth/gmail.send): Sends reminder alerts or daily agenda digests only after your explicit confirmation.
Google API Services User Data Policy — Limited Use Disclosure:
reminderme’s use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy , including the Limited Use requirements.

Strict Prohibitions on Google User Data

  • We never sell, rent, or use Google user data for advertising.
  • We never use Google Workspace data to train AI or ML models.
  • Google OAuth access tokens are stored strictly in active browser memory and cleared on sign-out or reload.

3. Data Security, Revocation & Deletion

All data in transit is encrypted via HTTPS/TLS, and cloud reminders are protected by owner-only Firebase Firestore rules. You may revoke Google access anytime at https://myaccount.google.com/permissions, or email appuprajju807@gmail.com to request complete deletion of your account and cloud data within 7 business days.
